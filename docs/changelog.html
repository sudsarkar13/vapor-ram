Version History & Changelog

Detailed release notes, feature highlights, performance optimizations, and bug fixes across all versions.

v1.0.7-alpha.1 Alpha Preview
2026-08-02
🚀 Highlights & Features
  • Next.js + shadcn/ui Dashboard Migration: Rebuilt the local Web UI with Next.js, Tailwind CSS, and shadcn/ui featuring real-time SSE streaming, syntax highlighting, and 0 end-user Node.js dependencies.
  • Dynamic Context Window Endpoint (/system/context): Added runtime context adjustment endpoint to dynamically scale context window (n_ctx) between 512 and 8,192 tokens.
  • Concurrent Slot Guarding: Introduced slot locks (_slot_begin / _slot_end) and graceful SSE disconnect handling.
v1.0.6 Stable Release
2026-08-01
🚀 Highlights & Features
  • Apple Silicon MacBook Support: Expanded hardware inspector (doctor.py) to identify Apple Silicon M-Series chipsets (M1, M2, M3, M4, M5, A18 Pro) and ARM NEON / AMX matrix extensions.
  • Expanded Max Output Limit: Increased max generation token ceiling to 8,192 tokens.
  • Linux Terminal Signal Clean Shutdown: Updated HTTP server socket timeout and SIGINT signal handler to cleanly terminate immediately on CTRL+C.
v1.0.5 Stable Release
2026-07-31
🚀 Highlights & Features
  • Double-Buffer O_DIRECT Layer Streamer: Initial C engine release supporting 140 MB/layer POSIX unbuffered streaming with AVX2 SIMD matrix kernels.
