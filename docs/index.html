Run Gemma 4 E4B-it — an 8-billion parameter state-of-the-art language model — on laptops and desktops under 1.5 GB RAM. Pure C SIMD engine, unbuffered O_DIRECT SSD layer streaming, zero memory pressure.

Memory vaporized. Layers streamed.

Traditional engines load 16GB+ of weights into system RAM. VaporRAM streams 140MB transformer layers sequentially from NVMe SSD into a double-buffered 300MB workspace, reducing active memory consumption to under 145 MB.

Quickstart & Installation
Get up and running in seconds via PyPI or source executable.

1. Install via PyPI

pip install vapor-ram

2. Launch Web Dashboard

vapor web
# Launches local HTTP server and opens http://localhost:8000/

3. Host Network LAN Gateway

vapor serve --host 0.0.0.0 --port 8000
# Exposes /v1/chat/completions and /v1/responses endpoints to local devices
